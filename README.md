# TFT Meta

A Windows overlay for **Teamfight Tactics** (Set 18).

It reads your game screen — shop, traits, items, gold, level, HP and augments — and helps you pick and play a build:
top builds from bunnymuffins and TFT Academy, with tiers checked against SeeMeta's ranked results; the chosen build's
board, items and stage-by-stage guide; flashing "BUY" hexagons for units worth buying; leveling and gold advice; and a
history of your games. A guide mode shows a picked build without reading the screen.

Game data, icons and guides are downloaded when it starts.
